{# docs/11 §8's rule, applied to write-backs: never let a failure be quiet. Every action on this dashboard is an HTMX post whose response replaces a panel, and HTMX swaps nothing on a non-2xx — so before this existed, a refused write (a commitment already resolved, a source that vanished) produced no swap, no message and no console line. A click that does nothing at all is indistinguishable from a click that worked, which is the failure mode the Sources panel exists to prevent one layer up. It waits to be dismissed rather than timing out: a write the owner believes happened and did not is worth an interruption. #} {# Empty at rest, deliberately: the chip is built in JS when a write actually fails.
